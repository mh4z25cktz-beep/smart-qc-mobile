# 프로젝트명: 스마트 공정 품질 관리 시스템 (Cloud Web Ver 2.0)
## 1. 목적: 전통적인 통계적 공정 관리(SPC) 기법과 최신 머신러닝(ML) 기반 예측 기법을 결합한 Vercel 배포형 클라우드 웹 애플리케이션 개발
## 2. 타겟 사용자: 제조 현장 품질 관리자, 공정 작업자 및 원격 관제 모니터링 관리자
## 3. 핵심 기능 (Ver 2.0)
1. 공정 데이터 수집 및 실시간 SPC 관리: 온도, 습도, 치수를 웹 브라우저에서 입력받아 Supabase 클라우드 DB에 실시간 저장하고 관리상하한선(UCL/LCL) 이탈 여부 판별 및 Chart.js 관리도 시각화.
2. 불량 확률 예측 및 원인 분석 (ML): 공정 환경 데이터를 바탕으로 Random Forest 알고리즘을 활용해 불량 발생 확률을 예측하고, Feature Importance를 계산하여 지능형 원인 분석 코멘트 출력.
3. Vercel 원클릭 클라우드 배포: Vercel Serverless Function 및 Supabase 기반으로 전 세계 어디서나 웹 브라우저로 접근 가능한 고가용성 아키텍처.
