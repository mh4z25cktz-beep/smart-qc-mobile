# 필수 준수 규칙 (Mobile App Ver 3.0)

1. [수정] 모바일 실행 환경 호환성: Expo Go(iOS/Android) 환경에서 네이티브 빌드 충돌 없이 즉시 실행되도록 순수 TypeScript 및 Expo 기본 호환 라이브러리 중심으로 구성.
2. [유지] 데이터베이스 연동 안정성: 기존 웹과 동일한 Supabase REST API(`apikey`, `Bearer`) 및 `qc_data` 테이블을 사용하며, 네트워크 지연 또는 오프라인 시에도 앱이 다운되지 않도록 인메모리 폴백 캐시 보장.
3. [수정] 모바일 입력 및 예외 처리: 스마트폰 숫자 키패드(`decimal-pad`) 적용 및 실시간 입력 범위 검증으로 비정상 입력(빈 값, NaN, 범위 초과) 및 네트워크 예외 안전 차단.
4. [유지] 핵심 알고리즘 보존: 전통적 SPC(3-Sigma) 관리한계선(CL, UCL, LCL) 및 특성 중요도(Feature Importance) 기반 지능형 원인 분석 코멘트 로직 유지.
5. [신규] 모바일 UI/UX 표준 준수: 한 손 조작을 고려한 하단 탭 내비게이션, 상단 노치/상태바 침범 방지(`SafeAreaView`), 이상치(OUT_OF_CONTROL 또는 고위험 불량) 감지 시 시각적 배지 및 햅틱 피드백 제공.
