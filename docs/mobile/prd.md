# 프로젝트명: 스마트 공정 품질 관리 모바일 앱 (Mobile App Ver 3.0)

## 1. 목적
- [유지] 전통적인 통계적 공정 관리(SPC) 기법과 머신러닝(ML) 기반 불량 예측 기법을 결합한 품질 관리 시스템 구축
- [수정] 기존 PC 웹 브라우저 중심의 대시보드(Cloud Web Ver 2.0)를 현장 이동성과 즉시성을 극대화한 iOS/Android 크로스플랫폼 모바일 앱(React Native / Expo)으로 확장

## 2. 타겟 사용자
- [유지] 제조 현장 품질 관리자, 공정 작업자 및 관제 관리자
- [수정] 생산 라인을 순회하며 스마트폰으로 현장에서 즉시 측정치를 입력하고 이상 여부를 확인하는 현장 작업자

## 3. 핵심 기능 (Ver 3.0)
1. [수정] 모바일 공정 데이터 수집 및 실시간 SPC 관리: 스마트폰 숫자 키패드로 온도(`temperature`), 습도(`humidity`), 치수(`dimension`)를 입력받아 기존 웹과 동일한 Supabase 클라우드 DB(`qc_data`)에 실시간 저장하고, 3-Sigma 관리상하한선(UCL/CL/LCL) 이탈 여부 판별 및 모바일 터치 최적화 SPC 관리도 시각화.
2. [수정] AI 불량 확률 예측 및 원인 분석: 입력된 공정 데이터를 바탕으로 불량 발생 확률(`defect_prob`) 및 불량 판정(`is_defect`)을 산출하고, 변수별 특성 중요도(Feature Importance) 기반 지능형 원인 분석 코멘트를 모바일 카드 UI로 제공.
3. [신규] 웹-모바일 실시간 양방향 클라우드 동기화 및 현장 피드백: 기존 배포 웹(`smart-qc-web-ten.vercel.app`)과 동일한 Supabase `qc_data` 테이블을 공유하여 웹과 모바일 간 데이터를 실시간 동기화하고, 관리한계선 이탈 또는 고위험 불량 감지 시 시각적 경고 배지 및 햅틱(진동) 알림 제공.
